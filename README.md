# Ayiti an Avan — redesign mockup

Design proposal for [ayitianavan.com](https://ayitianavan.com): homepage, article page, live TV page and Shorts (vertical video) player, plus a site audit.

- `index.html` — the redesign (Accueil, Article, TV en direct, Shorts)
- `audit.html` — audit of the current site and the plan to implement the redesign in WordPress

Static HTML/CSS/JS, no build step. Content is example content taken from ayitianavan.com.
